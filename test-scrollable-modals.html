🎨 Scrollable Modals - UX Polish Test

Testing sticky footer buttons with scrollable modal bodies

✨ Feature Overview

🔒 Sticky Header

Modal title stays fixed at the top, providing context while scrolling

📜 Scrollable Body

Long form content scrolls smoothly within the modal body area

📌 Sticky Footer

OK/Cancel buttons remain visible and accessible at all times

🎯 Custom Scrollbar

Themed scrollbar matches dark/light mode with smooth appearance

📱 Responsive

Adapts to viewport height, preventing overflow on smaller screens

♿ Accessible

Keyboard navigation and screen reader friendly

🧪 Interactive Tests

📋 Test Instructions

  • Click the test buttons below to open NovaPlan modals
  • Try modals with many form fields (Calendar Settings, Custom Fields)
  • Resize your browser window to test responsiveness
  • Verify buttons stay visible while scrolling

✅ What to Verify

  • Modal header (title) remains visible at top while scrolling
  • Modal footer (buttons) remains visible at bottom while scrolling
  • Body content scrolls smoothly between header and footer
  • Scrollbar appears only when content exceeds viewport
  • No content is cut off or hidden
  • Buttons are always clickable (not obscured)
  • Works on different screen sizes

💻 CSS Implementation

/* Scrollable Modal with Sticky Footer */ .modal-box { max-height: calc(100vh - 48px); display: flex; flex-direction: column; overflow: hidden; /* Prevent box overflow */ } .modal-head { flex-shrink: 0; /* Don't shrink header */ z-index: 1; } .modal-body { flex: 1; /* Take remaining space */ overflow-y: auto; /* Scroll when needed */ min-height: 0; /* Allow flex shrink */ } .modal-foot { flex-shrink: 0; /* Don't shrink footer */ z-index: 1; /* Stay above body */ }
